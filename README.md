# Portfólio Rodrigo Pereira do Ó

Landing page profissional, responsiva e sem dependências de framework.

## Como usar
1. Abra `index.html` no navegador.
2. Para publicar, envie os arquivos para sua hospedagem.

## Estrutura
- `index.html` — conteúdo da landing page
- `style.css` — identidade visual e responsividade
- `assets/rodrigo.jpg` — foto fornecida para o projeto
